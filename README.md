# Jeju-Tour

전주 출발 제주도 3박 4일 자전거 여행 공유 페이지입니다.

## 페이지

- `index.html`: 홈
- `course.html`: 코스와 네이버지도 맵
- `schedule.html`: 일자별 일정표
- `live.html`: 네이버지도, 배편, 기차편, 버스편 실시간 확인 링크
- `transport.html`: 출발, 배편, 복귀 운영안
- `meeting.html`: 2026-09-21 제주 3박 4일 라이딩 운영계획 회의자료 열람 및 PDF 다운로드
- `event.html`: 2026-09-07~2026-10-31 제주라이딩 30분 체력훈련 챌린지 페이지

## 회의자료

알림 → 회의에서 첨부 회의자료 전체를 미리볼 수 있습니다. `meeting.html`에서는 전체 화면 열람, 이미지 확대, PDF 원본 보기와 다운로드를 제공합니다. 로그인이나 인증 서버 API 없이 정적 사이트에서도 열립니다.

- 회의 메뉴: `course.html?panel=meeting` (기존 `?panel=event` 링크도 회의 메뉴로 연결)
- PDF 원본: `assets/meetings/jeju-riding-operation-plan.pdf`
- 1페이지 미리보기: `assets/meetings/jeju-riding-operation-plan-page-1.png`

사이트를 배포할 때 `meeting.html`과 `assets/meetings`를 함께 포함하세요. 다른 사람에게는 배포된 사이트의 `/meeting.html` 주소를 공유하면 됩니다. `localhost` 주소는 해당 컴퓨터에서만 열립니다.

## 사진 인증 서버

기존 인증 페이지(`event.html`)에서는 사진 첨부, 이름별 서버 저장, 인증 참가자 집계, 참가자를 클릭한 인증 내역과 사진 조회를 계속 지원합니다. 알림 메뉴의 이벤트 항목은 회의로 변경되었습니다.

Node.js 24.14 이상 24.x를 설치한 뒤 `server/start-server.cmd`를 실행하거나 프로젝트 폴더에서 `npm start`를 실행하세요. 회의는 `http://localhost:3000/course.html?panel=meeting`, 기존 인증 페이지는 `http://localhost:3000/event.html`로 접속합니다.

- 사진: 선택 첨부, 최대 3장, JPG/PNG/WebP 장당 8MB
- 저장: `server/data/participants/이름--고유ID/날짜/인증ID/`와 SQLite DB
- 집계: 30분 이상, 같은 참가자·날짜당 1점
- 관리: 관리자 키로 개별 삭제, 이름별 JSON/CSV 내보내기, DB·사진 전체 백업
- 검증: `npm test`

서버 폴더와 데이터를 포함한 프로젝트 전체를 다른 컴퓨터로 복사하여 실행할 수 있습니다. **[서버 실행·관리·백업·이전 안내](server/README.md)**를 참고하세요. 기본 설정은 현재 PC에서만 접속되며, 다른 기기의 접속 설정도 안내에 포함되어 있습니다.

## GPX 코스 분석

**교통&코스 → 코스**에서 첨부 GPX 4개의 실제 주행 기록을 바로 확인합니다. 데스크톱에서는 좌측 메뉴와 전체 지도를 유지하며, 메뉴 오른쪽 지도 하단의 접을 수 있는 패널에서 분석합니다. 모바일에서는 지도·사고·사진 / 주행 분석 화면을 전환합니다. GPX 전용 탭은 코스 탭으로 통합했습니다. 직접 링크는 course.html?panel=course이며 기존 panel=gpx 링크도 코스로 연결됩니다.

| 일차 | 기본 GPX 경로 | 지도 색상 |
| --- | --- | --- |
| 1일차 | 제주항 → 카이리조트 | 주황 |
| 2일차 | 카이리조트 → 더베이제주리조트 | 파랑 |
| 3일차 | 더베이제주리조트 → 아쿠아뷰티크 | 초록 |
| 4일차 | 아쿠아뷰티크 → 제주항 | 보라 |

원본 4개 파일은 assets/gpx에 포함되어 다른 기기에서도 기본으로 표시됩니다. 이전 계획 코스는 회색으로 유지합니다.

- 시간·거리 축 전환, 누적 거리·속도·고도의 면적 그래프, 기록이 있는 심박·케이던스·파워
- 구간 시작·끝 슬라이더로 그래프 확대, 그래프·위치 슬라이더·30초 요약 재생과 지도 위치 연결
- 5km 구간별 시간·거리·평균/최고 속도·상승/하강, 구간 행을 누른 지도 위치 표시
- 주행 요약, 선택 일차/4일 전체 지도 보기, 원본 GPX 및 전체 지점 CSV 다운로드
- 선택한 일차의 GPX 교체, 기기별 저장·복원, 첨부 코스로 복구, 기존 계획 코스 편집

첨부 파일에는 시간과 고도 기록이 있으며 속도는 좌표 간 거리와 시간으로 계산합니다. 평균 속도는 정지 시간을 포함하고 이동 평균 속도는 1 km/h 이상인 구간 기준입니다. 그래프의 지점 평균은 해당 구간의 개별 측정값 평균입니다. 시간은 한국 시간으로 표시합니다. 5km 경계에서는 연속 기록 사이를 비례 분할합니다. 분리된 트랙 사이의 거리와 시간은 합산하지 않으며 없는 기록은 추정하지 않습니다. 고도 합계는 원본 측정값 기준으로 GPS 오차가 포함됩니다.

GPX 1.0/1.1 트랙과 경로를 지원하며 파일당 최대 20MB, 150,000개 지점까지 읽습니다. 교체한 파일은 브라우저 IndexedDB에 일차별로 저장되고 다른 기기에 공유되지 않습니다. 기기 저장이 불가능해도 현재 화면의 분석은 사용할 수 있습니다. 배포에는 gpx-core.js, gpx-viewer.js와 assets/gpx를 포함합니다.

## 사고지점과 함께 찍은 사진

코스의 **사고지점 · 함께 찍은 사진 → 등록**에서 유형, 제목과 설명을 입력합니다. 지도에서 위치를 직접 선택하거나 현재 GPX 선택 지점을 사용합니다. 사고지점은 사진 없이 저장할 수 있고, 사진 기록에는 한 장 이상을 첨부합니다. JPG·PNG·WebP 사진은 최대 3장, 장당 8MB까지 저장합니다.

저장한 위치에는 사고/사진 마커가 생깁니다. 마커나 기록 목록의 지도 위치를 누르면 팝업이 열리고, 사진 또는 내용·사진 버튼을 누르면 확대 화면에서 설명과 모든 사진을 확인할 수 있습니다. 기본은 선택한 일차만 표시하며 4일 전체 기록도 볼 수 있습니다.

등록은 기존 Node 서버 API를 사용합니다. 같은 서버에서 사이트를 실행하면 npm start 후 /course.html?panel=course에서 바로 저장됩니다. 정적 사이트만 배포하면 저장 API가 없으므로, 별도 서버를 사용할 때 event-config.js의 JEJU_EVENT_API_BASE와 server/config.json의 allowedOrigins를 설정합니다. 연결 실패 시 저장 버튼을 비활성화하고 서버 연결 상태를 표시합니다.

운영 사이트와 localhost의 코스 사진은 **Supabase Database·Storage**에 저장합니다. **PC와 로컬 서버를 꺼도** [배포된 코스 탭](https://jeju-gaja.vercel.app/course.html?panel=course)에서 계속 조회할 수 있습니다. 등록은 기존 **함께가기 → 개인 초대 참가자 인증**을 재사용하며, 저장된 사진과 장소 기록은 여행 사이트에 공개됩니다. 위치 공유는 별도 동의로 시작합니다. 저장 권한·배포·검증 안내는 [코스 사진 클라우드 저장](docs/course-cloud-storage.md)을 참고하세요. 기존 Node의 로컬 저장·백업 API는 관리 호환용으로 유지합니다.

## 선택 지점과 휴식 후보의 카카오 로드뷰

코스 지도의 GPX 지점 팝업에서 **이 위치 로드뷰**, 주행 분석에서 **선택 지점 로드뷰**를 누르면 해당 좌표의 가장 가까운 카카오 로드뷰를 엽니다. 데스크톱은 지도 오른쪽에 표시하여 아래 분석 패널과 함께 사용하고, 모바일은 닫을 수 있는 전체 화면을 사용합니다. 열린 상태에서 그래프나 위치 슬라이더의 선택을 바꾸면 로드뷰 좌표도 갱신됩니다. 로드뷰에서 이동하면 파란 촬영 위치 표시가 지도에 반영되며, 원본 GPX 선택 위치는 유지됩니다. 로드뷰는 촬영 당시의 모습입니다.

**장시간 머문 곳** 목록, 지도의 일차 색상 Ⅱ 표시, 그래프의 노란 구간을 누르면 해당 장소의 지도와 로드뷰가 연결됩니다. 기본 기준은 첫 지점 반경 40m 안의 5분 이상 체류 후보이며 최소 시간을 5·10·20분으로 바꿀 수 있습니다. 좌표 평균에 가장 가까운 실제 GPX 지점을 사용합니다. 분리된 트랙과 없거나 역전된 시간은 연결하지 않습니다. 연속 측정 사이의 공백이 2분을 넘으면 **기록 공백 포함**으로 표시합니다. 파일이 정지 중에 기록을 생략할 수 있으므로 이 시간을 확정된 휴식 시간으로 보지 않습니다.

로드뷰 키는 roadview-config.js의 JEJU_KAKAO_JAVASCRIPT_KEY에 설정합니다. JavaScript 키는 브라우저에서 사용하는 공개 키이며 REST API 키나 Admin 키를 넣으면 안 됩니다. 카카오 개발자 사이트의 해당 키 → **JavaScript SDK 도메인**에 실제 접속 출처를 등록해야 합니다. 로컬 서버는 http://localhost:3000이며 http://127.0.0.1:3000이나 다른 포트를 사용하면 그 출처도 별도로 등록합니다. SDK의 지도 사용 설정도 활성화되어 있어야 합니다. [카카오 공식 설정 안내](https://apis.map.kakao.com/web/guide/)를 참고하세요.

주변 50m, 이후 100m 안에서 파노라마를 검색합니다. 로드뷰가 없거나 연결이 실패해도 선택 좌표의 **카카오맵에서 로드뷰 보기** 링크를 사용할 수 있습니다. 사이트 배포 파일에는 roadview.js와 roadview-config.js를 포함합니다.

## 지정 사고 장소

코스에는 1일차의 **1번·2번 사고 장소**를 기본 표시합니다. 1번은 사용자가 확인한 **CU 앞 GPX 정지 지점**(33.4970366, 126.4519783)에 표시하고, 입력 주소인 제주시 이호일동 1962번지를 함께 안내합니다. 이호일동 1962의 주소 대표 좌표는 이 지점과 약 230m 다르므로, 주소 검색 결과로 1번 위치를 덮어쓰지 않습니다. 2번은 카카오 주소 검색으로 확인한 **제주시 한림읍 귀덕리 3025-4**(33.442234993172, 126.289658570096)에 표시합니다.

빨간 번호 마커, 지정 사고 장소 목록, 그래프의 빨간 표시를 누르면 해당 위치와 관련 GPX 정지 기록이 연결됩니다. 관련 정지 구간은 시간 축에서 확대하며 거리·속도·고도 그래프에 표시됩니다. 사고 발생 시각은 별도로 주어진 정보가 없어 추정하지 않고, 연결된 GPX 시각과 정지 기록만 안내합니다. 기록 공백을 포함한 시간은 기존과 같이 구분합니다. 다른 GPX로 교체하여 근처 기록이 없는 경우 관련 지점을 임의로 연결하지 않습니다.

기본 사고 장소는 course-incidents.js에 포함되어 서버 연결 여부와 관계없이 표시되며 배포 파일에도 포함됩니다. 사용자가 등록하는 사고·사진의 서버 저장 기능은 기존처럼 사용할 수 있습니다. 데스크톱 지도 오른쪽에는 내 위치 아이콘을 도착 알림 아이콘 위에 배치하며, 로드뷰 패널이 열려도 두 아이콘이 가려지지 않게 오른쪽 여백을 둡니다.
1일차 체류 말머리는 #1·#2 물항식당, #3 첫번째 사고지점, #5 가방 잃어버린 곳 · 곽지해변 화장실, #6 두번째 사고지점, #7 버스정류장, #8 흑돼지 바당돈으로 표시합니다. 이름은 지도에 상시 표시하며 체류 목록·그래프 구간 설명·선택 지점 팝업·로드뷰 제목에도 적용합니다. 최소 체류 시간 필터를 바꿔도 원래 번호를 유지합니다. 이름은 해당 1일차 기록의 위치와 맞는 경우에 적용합니다.
### 일차별 체류 장소 이름

1일차 #1·#2 물항식당, #3 첫번째 사고지점, #5 가방 잃어버린 곳·곽지해변 화장실, #6 두번째 사고지점, #7 버스정류장, #8 흑돼지 바당돈은 사용자가 지정한 이름을 유지합니다. 2일차 9곳·3일차 10곳·4일차 6곳은 GPX 대표 좌표를 카카오 지번 주소·주변 시설·기존 숙박 일정과 대조해 이름을 붙였습니다. 방문 시설을 확정하기 어려우면 ‘인근’이나 해안 구간 이름으로 표시합니다.

데스크톱에서 선택한 일차의 장소 이름을 지도에 상시 표시하며 다른 일차는 마커에 마우스를 올리면 이름을 볼 수 있습니다. 모바일 축소 지도에는 체류 번호를 표시하고 가까이 확대하면 장소 이름도 표시합니다. 체류 목록·주행 그래프·선택 지점 팝업·로드뷰 제목에 같은 이름을 사용합니다. 목록의 **장소·주소 확인**에서 주소, 판단 근거와 카카오맵 기준 장소 링크를 확인합니다. 5·10·20분 필터에서도 번호는 유지됩니다.

이름 데이터와 출처는 course-stop-labels.js에 있으며 원본 번호와 대표 좌표 반경 50 m 안에서만 적용합니다. 다른 위치의 GPX로 교체하면 기존 이름을 강제로 붙이지 않습니다. [전체 25곳의 위치와 판단 근거](docs/gpx-stop-places.md)를 참고하세요. 사이트 배포에는 course-stop-labels.js도 포함합니다.

### 정지 표시의 장소·사진 카드

지도에서 정지 번호 또는 장소 말머리를 누르면 이름, 위치 주소, 체류 시간과 등록된 사진을 함께 보여줍니다. 데스크톱에서는 지도 안 팝업, 모바일에서는 화면 안 상세 카드로 열립니다. 주행 분석의 지도·로드뷰 버튼은 기존처럼 해당 위치의 로드뷰를 엽니다.

사진은 Supabase의 사고지점·함께 찍은 사진 기록 중 **같은 일차이며 정지 대표 지점 반경 50 m 안**에 등록된 사진을 연결합니다. 다른 일차나 떨어진 위치의 사진은 섞이지 않습니다. 사진을 누르면 원본 사진과 설명을 확대해 확인합니다. **이 장소 사진 등록**은 일차·위치를 자동 선택하고 Supabase 저장 폼을 엽니다. 사진이 없는 장소와 서버 연결 실패는 서로 구분해 표시합니다. 저장 후 다시 누르거나 새로고침해도 클라우드 사진이 표시됩니다.

1일차의 이름은 사용자 지정 내용을 유지하며 GPX 좌표의 주소를 추가했습니다. 두 사고 장소는 사용자 지정 사고 주소를 우선 표시하고 장소 확인 근거 안에 GPX 대표 좌표의 주소를 함께 표시합니다. 사이트 배포에 course-stop-card.js를 포함하세요.
